# IFE-A — Inventário de Funções Executivas no Adulto

Questionário clínico de autorrelato, com 60 itens originais em 10 domínios, sem normas populacionais.
© 2026 Gustavo Coutinho de Faria. Uso clínico.

- **Paciente:** `https://<usuario>.github.io/<repositorio>/`. Responde no celular e recebe um código sem identificação.
- **Médico:** `https://<usuario>.github.io/<repositorio>/#medico`. Cola o código e obtém o perfil e o texto para o prontuário.

Nenhuma resposta é enviada pela internet. O progresso fica salvo só no aparelho do paciente, por até 48 h.

## Atenção ao editar
O código depende da **ordem e do número de itens**. Para mudar, incluir ou remover um item, troque `VER = "IFE1"` por `"IFE2"` e mantenha a lógica antiga para decodificar códigos IFE1.
Já mudar só a redação de um item não quebra os códigos, mas altera o instrumento.
